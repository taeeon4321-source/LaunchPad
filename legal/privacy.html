What we collect and why

  • Account information: email, display name, optional profile image, password hash (Argon2id; we never store your password), account dates. Used to run your account.
  • Authentication identifiers: your Google account's stable ID (sub) and email if you use Google sign-in; session records (time, IP address, browser) for security.
  • Game information: games, reports, recommendations and corrections you create.
  • Roblox connection: your Roblox user ID, username, the experiences you authorize, and encrypted OAuth tokens. We never ask for your Roblox password or cookies.
  • Uploaded images: artwork you upload for analysis.
  • Scan evidence: the summary the LaunchPad Studio plugin sends: names, counts, interaction prompts, UI text, number values and paths of relevant objects.
  • Source-code information (only if you allow it): the plugin reads scripts inside Studio and sends only feature names, script paths and numbers from configuration tables. Raw source code is not sent to LaunchPad.
  • Pricing analytics: anonymous events such as "viewed pricing", "chose annual" or "started checkout", with a random id that lasts one browser tab. No account, IP address or cookie is attached, and nothing is sent when your browser asks not to be tracked.
  • Security logs: sign-ins, failed attempts, security changes and administrator actions.
  • Billing references: Paddle customer, subscription and transaction IDs, plan, amounts and status. Paddle processes your payment details; we never receive card numbers.
